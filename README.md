# Spend Audit Platform

A modern, AI-powered platform for reviewing and managing recurring payments with intelligent analysis and automated cancellation recommendations.

## 🎯 Overview

Spend Audit Platform is a sophisticated financial management tool that leverages artificial intelligence to analyze recurring charges, identify potential savings, and generate actionable cancellation messages. The platform provides a comprehensive solution for businesses and individuals to optimize their subscription expenses and avoid unnecessary charges.

## 🚀 Key Features

### 🤖 AI-Powered Analysis
- **Intelligent Recurring Review**: Automatically analyzes recurring payments and subscriptions
- **Smart Recommendations**: Provides cut/review/keep recommendations for each charge
- **Cost Optimization**: Identifies potential savings opportunities
- **Cancellation Drafting**: Generates professional cancellation messages

### 📊 Comprehensive Dashboard
- **Real-Time Tracking**: Monitor all recurring charges in one place
- **Visual Analytics**: Clear charts and graphs for financial insights
- **Smart Filters**: Organize and categorize charges effectively
- **Mobile-Responsive**: Access from any device

### 🛡️ Secure & Private
- **Bank-Grade Security**: Your financial data is completely private
- **No Statement Sharing**: Never send your bank statements or personal information
- **Direct Integration**: Connect securely with your payment providers
- **Local Processing**: Your data stays with your provider

## 📈 What It Does

### 1. **Charge Discovery**
   - Reads and analyzes all recurring charges in your statements
   - Categorizes by merchant, amount, and frequency
   - Identifies patterns and trends over time

### 2. **AI Analysis**
   - Evaluates each charge for necessity and value
   - Provides actionable recommendations (cut/review/keep)
   - Calculates potential yearly savings
   - Generates professional cancellation messages

### 3. **Smart Action**
   - Prioritize charges for review or cancellation
   - Send cancellation notices directly from your email
   - Track the impact of your decisions over time
   - Set up automatic re-reviews for suspicious patterns

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- pnpm 8+

### Installation

```bash
# Clone the repository
https://github.com/yourusername/spend-audit-platform.git

# Navigate to the project directory
cd spend-audit-platform

# Install dependencies
pnpm install

# Run the development server
pnpm dev

# Build for production
pnpm build

# Start the production server
pnpm start
```

### Live Demo
Explore the live demo of the platform:
[http://localhost:4000](http://localhost:4000)
