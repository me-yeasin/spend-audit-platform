# Test fixtures

Drop these files onto the homepage card to check every upload and list state.
All of them are generated by `generate.mjs` — deterministic, no randomness.

| File | Size | What it should show |
|---|---|---|
| `statement-3-months.csv` | 2 KB · 62 rows | **Imported** — the everyday happy path (Aug–Oct 2026) |
| `statement-12-months.csv` | 9 KB · 250 rows | **Imported** — a full year, handy for month-over-month later |
| `large-statement.csv` | 892 KB · 24,000 rows | **Reading → Imported** — progress bar is clearly visible, then a paged list |
| `empty.csv` | 0 bytes | **Rejected** — "That file is empty" |
| `statement.pdf` | 90 bytes | **Rejected** — "That file is a PDF" |
| `oversized-statement.csv` | 11 MB | **Rejected** — "That file is 11 MB · The limit is 10 MB" |
| `header-only.csv` | 25 bytes | **Imported, no rows** — the "No transactions found" list state |
| `unreadable.csv` | 22 bytes | **Imported, unreadable** — "Couldn't read this statement" list state |

`large-statement.csv` and `oversized-statement.csv` are gitignored because they are
bulky and regenerable. Every other file is committed.

## Regenerate

```bash
node test-data/generate.mjs
```

## What the data looks like

```
Date,Description,Amount
2026-08-01,CITY APARTMENTS RENT,-1850.00
2026-08-02,NETFLIX.COM,-15.49
2026-08-04,"WHOLE FOODS MARKET #123, AUSTIN TX",-87.43
2026-08-15,PAYROLL DEPOSIT ACME CORP,4200.00
```

Three months of realistic activity: 14 charges that repeat every month with a stable
description and amount (rent, streaming, software, gym, insurance, phone), a utility
bill whose amount drifts, a salary credit, plus one-off groceries, coffee, rideshare
and pharmacy spends. Descriptions with commas are quoted, which the parser handles.

## Manual checks

1. Drag `statement-3-months.csv` anywhere on the page → the hero collapses, the file
   chip shows `62 rows`, and the list groups three months, newest first.
2. Drag `statement.pdf` → red rejected state naming the type, with "Choose another file".
3. Drag `large-statement.csv` → determinate progress, then `24,000` transactions with a
   "Showing 500 of 24,000" footer and a **Show 500 more** button.
4. Drag `oversized-statement.csv` → size-limit message.
5. Drag `empty.csv` → empty-file message.
6. Drag `header-only.csv` → the list shows "No transactions found".
7. Drag `unreadable.csv` → the list shows "Couldn't read this statement".
8. Click **Replace file** on an imported file → file picker opens; cancel keeps the file.
9. Click **Remove** → the page returns to the landing hero and the upload card.
